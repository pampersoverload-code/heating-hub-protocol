# 00-07: Hub program-row acknowledgement

**Total: 17 application bytes.** Working GO_TX target: request sync+35.1ms, nominal RF sync gap about36.7ms. Carries no schedule points.

This example is sanitized: identities/association and illustrative calendar bytes are substituted, checksum recomputed. It is not an untouched capture.

```text
7E 2B 00 07 00 0A A1 B2 C3 D4 10 20 30 40 03 06 4D
```
