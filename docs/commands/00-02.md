# 00-02: Hub association response candidate

**Total: 25 application bytes.** Contains assigned slot; normal status followed about3s later. This is partial association evidence, not a tested pairing implementation.

This example is sanitized: identities/association and illustrative calendar bytes are substituted, checksum recomputed. It is not an untouched capture.

```text
7E 2B 00 02 00 12 A1 B2 C3 D4 10 20 30 40 03 FF FF 1A 01 02 03 04 05 01 72
```
