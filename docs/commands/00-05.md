# 00-05: Hub presence response

**Total: 16 application bytes.** No extra temperature or full calendar payload. Working GO_TX target: request sync +27.2ms. A 01-01/00-01 exchange commonly follows.

This example is sanitized: identities/association and illustrative calendar bytes are substituted, checksum recomputed. It is not an untouched capture.

```text
7E 2B 00 05 00 09 A1 B2 C3 D4 10 20 30 40 03 44
```

| Offset | Length | Field | Encoding | Confidence | Interpretation |
|---|---:|---|---|---|---|
| 0..1 | 2 | Application marker | hex | Confirmed | 7E 2B, not the RF sync word. |
| 2..3 | 2 | Kind | two raw bytes | Confirmed | Classify together with total frame length. |
| 4..5 | 2 | Payload length | BE16 | Confirmed | Total application length = this value + 7. |
| 6..9 | 4 | Thermostat ID | opaque bytes | Confirmed | Destination association. |
| 10..13 | 4 | Hub/network ID | opaque bytes | Confirmed | Source association. |
| 14 | 1 | Association slot | unsigned | Observed | 1..6 in this system; not a universal hardware ID. |
| 15 | 1 | Additive checksum | sum8 | Confirmed | Sum offsets 0..14 modulo 256. |
